```mermaid
sequenceDiagram

    System->>Gateway: Trigger Incident Telemetry Alert
    Gateway->>IncidentAgent: Route Payload for Automated Classification
    IncidentAgent->>RAG: Retrieve Past Incident Tickets & Documentation
```
