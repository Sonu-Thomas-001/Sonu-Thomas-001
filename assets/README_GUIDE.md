## 🛠️ GitHub Actions Setup Instructions

### 1. Enable Snake Contribution Animation Workflow
1. Go to **Settings** > **Actions** > **General** in your repository `Sonu-Thomas-001`.
2. Under **Workflow permissions**, select **Read and write permissions**.
3. Click **Save**.
4. Go to the **Actions** tab, select **Generate Snake Animation**, and click **Run workflow**.
5. Once executed, it will automatically create an `output` branch containing `github-contribution-grid-snake-dark.svg`.

### 2. Configure GitHub Readme Stats & Counters
- **Visitor Counter**: Uses `https://komarev.com/ghpvc/?username=Sonu-Thomas-001` automatically. No token required.
- **GitHub Stats & Top Languages**: Uses `github-readme-stats.vercel.app` API endpoints.
- **Streak Stats**: Uses `github-readme-streak-stats.herokuapp.com`.
- **Activity Graph**: Uses `github-readme-activity-graph.vercel.app`.
